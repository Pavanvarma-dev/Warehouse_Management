# Warehouse Management UI

Freestyle SAPUI5 MVC frontend for the Warehouse CAP service. It provides warehouse, storage-bin, product, inventory, and stock-movement views, plus forms for creating warehouse data and receiving or dispatching stock.

## Run

From the `warehouse-Management` project root, run:

```sh
npm run watch-warehouse
```

Open `http://localhost:4004/com.warehouse.warehouse/index.html`. The UI connects to the CAP service at `/warehouse/`.
